## GitHub Pages 배포

1. GitHub에 `HyeongSeok-Choi.github.io` 저장소(공개)를 만들고 이 폴더를 push
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`
3. 1~2분 뒤 https://hyeongseok-choi.github.io 에서 열림
